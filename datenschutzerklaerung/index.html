Datenschutzerklärung

Pflegepedia sammelt keine Personendaten. Es gibt keine Anmeldung, keine Formulare, keine Cookies, keine Werbung und kein Tracking.

Verantwortlich

Speicherung auf deinem Gerät

Damit du nicht jedes Mal neu wählen musst, speichert dein Browser lokal auf deinem Gerät zwei Dinge: deine gewählte Stufe und welche Nuggets du abgeschlossen hast. Diese Daten werden nicht an Pflegepedia oder Dritte übermittelt. Du kannst sie jederzeit löschen.

Hosting

Die Website wird über GitHub Pages bereitgestellt (GitHub Inc., USA). Beim Aufruf verarbeitet GitHub technisch notwendige Daten wie die IP-Adresse, zum Beispiel zur Sicherheit und Stabilität des Dienstes. Pflegepedia hat darauf keinen Zugriff. Weitere Informationen findest du in der Datenschutzerklärung von GitHub.

Schriften

Die Schriften sind direkt auf dieser Website gespeichert. Es wird keine Verbindung zu externen Schriftanbietern hergestellt.

Deine Rechte

Du hast nach dem Schweizer Datenschutzgesetz das Recht auf Auskunft. Da Pflegepedia keine Personendaten speichert, sind in der Regel keine Daten über dich vorhanden. Bei Fragen schreib an info@pflegepedia.ch.
